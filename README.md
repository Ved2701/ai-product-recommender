# AI Product Recommendation System

An AI-powered product recommendation web app built using React, Vite, and Groq API.

## Features
- User preference input
- AI-generated product recommendations
- Product filtering from local dataset
- Responsive React frontend
- Fast deployment using Vercel

## Tech Stack
- React
- Vite
- JavaScript
- Groq API (OpenAI-compatible)

## Example Queries
- cheap laptop
- gaming laptop
- premium phone
- phone under $500
- wireless headphones
- tablet for students
